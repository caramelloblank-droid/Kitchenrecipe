# Polaris Recipes PWA

PWA для Polaris PMC 0517 Expert.

## Быстрый запуск на Windows

Не запускайте `index.html` двойным кликом — браузер блокирует загрузку `recipes.json` через file://.

1. Распакуйте архив.
2. Откройте папку `PolarisPWA`.
3. Запустите `run-local.bat`.
4. Откроется `http://127.0.0.1:8765/`.

Требуется Python 3. Если Python уже установлен, ничего дополнительно настраивать не нужно.

Если браузер не открылся автоматически, вручную откройте:
`http://127.0.0.1:8765/`

## Обновление базы

Замените только `data/recipes.json`. Фильтр ингредиентов, предметный указатель, категории и поиск строятся автоматически из базы.

## Публикация как настоящей PWA

Для установки на телефон или ПК загрузите папку на HTTPS-хостинг, например GitHub Pages.
