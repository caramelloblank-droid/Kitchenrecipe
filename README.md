# Kitchenrecipe PWA

PWA для рецептов Polaris PMC 0517 Expert.

## GitHub Pages
Файлы должны лежать в корне репозитория:

- index.html
- app.js
- styles.css
- manifest.webmanifest
- service-worker.js
- data/recipes.json

После включения GitHub Pages приложение работает по адресу вида:
https://USERNAME.github.io/REPOSITORY/

`data/recipes.json` — единственный источник рецептов. Новые рецепты, ингредиенты, категории и теги автоматически появляются в интерфейсе.
